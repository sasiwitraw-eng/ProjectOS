หน้าจอคือแดชบอร์ดจำลองการทำงานของอัลกอริทึม **Producer-Consumer Problem** แบบ Multi-threaded ในระบบปฏิบัติการ 
โดยมีรายละเอียดแบ่งตามส่วนประกอบต่างๆ ดังนี้:

---

### 1. Header & Operation Mode (แถบด้านบน)

* **Title:** Producer-Consumer Multi-Threaded Engine
* **Mode:** `POSIX Semaphore` — ปัจจุบันระบบใช้ **Semaphore** (`sem_empty`, `sem_full`) ร่วมกับ **Mutex Lock** ในการจัดการ Synchronization เพื่อป้องกันปัญหา Data Race และเข้าถึง Buffer พร้อมกัน

---

### 2. Bounded Buffer Queue (แผงแสดงสถานะ Buffer ตรงกลางซ้าย)

* แสดงคิวเก็บข้อมูลขนาดความจุ 10 ช่อง (Slot 0 – Slot 9)
* **สถานะปัจจุบัน:** มีข้อมูลตกค้างอยู่ในคิว **6 ชิ้น** (Slot 4 ถึง Slot 9) ส่วน Slot 0 – Slot 3 ว่างอยู่
* **สีและ ID ของชิ้นงาน:**
* **ชิ้นงาน #15, #17, #20 (สีแดง):** ผลิตโดย Thread **P0**
* **ชิ้นงาน #16, #18, #19 (สีส้ม):** ผลิตโดย Thread **P1**



---

### 3. Control Panel (แผงควบคุมพารามิเตอร์ ตรงกลางขวา)

* **Producers (N): 2** — มี Thread ฝั่งผู้ผลิตทำงานอยู่ 2 ตัว (P0 และ P1)
* **Consumers (M): 2** — มี Thread ฝั่งผู้บริโภคทำงานอยู่ 2 ตัว
* **Capacity: 10** — ขนาดความจุสูงสุดของ Buffer
* **Prod Delay: 0.8s** — เวลาที่ Producer ใช้สร้างสินค้า 1 ชิ้น (0.8 วินาที)
* **Cons Delay: 1.2s** — เวลาที่ Consumer ใช้ดึงสินค้าไปประมวลผล 1 ชิ้น (1.2 วินาที)
* **Active Producer Threads:** แสดงสัญลักษณ์สีประจำตัวของ Thread ผู้ผลิต (P0 = Red, P1 = Orange)

> **วิเคราะห์สภาวะระบบ:** ฝั่ง Producer ผลิตได้เร็วกว่า (0.8s) ฝั่ง Consumer ที่ดึงไปใช้ (1.2s) ส่งผลให้สินค้าเริ่มสะสมเพิ่มขึ้นเรื่อยๆ จนคิวแน่นขึ้นมาที่ 60%

---

### 4. Real-Time Analytics & System Status (แผงสถิติตัวเลขด้านล่าง)

* **THROUGHPUT (2.0 items / sec):** ความเร็วในการประมวลผลจริง ณ ปัจจุบัน (ดึงข้อมูลสำเร็จ 2 ชิ้นต่อวินาที)
* **UTILIZATION (60.0%):** อัตราการใช้งานพื้นที่ Buffer ณ ตอนนี้คือ 6 จาก 10 ช่อง
* **THREAD BLOCKS:**
* **Prod: 0** — ฝั่งผลิตยังไม่เคยติดบล็อก (ยังไม่เกิดการรอเนื่องจาก Buffer เต็ม)
* **Cons: 0** — ฝั่งบริโภคยังไม่เคยติดบล็อก (ยังไม่เกิดการรอเนื่องจาก Buffer ว่าง)


* **TOTAL PROCESSED:**
* **Produced: 20** — ยอดรวมสินค้าที่ถูกผลิตทั้งหมดตั้งแต่นับเริ่มต้น = 20 ชิ้น
* **Consumed: 14** — ยอดรวมสินค้าที่ถูกดึงไปใช้ทั้งหมด = 14 ชิ้น
* *(คงเหลือใน Buffer = 20 - 14 = 6 ชิ้น ซึ่งตรงกับช่องในคิวปัจจุบันพอดี)*
